# 面向 AI Agent 的 MCP 访问

Cosmosh 可以在你的 AI Agent（Claude Code、Claude Desktop、Cursor 及其他 MCP 客户端）与你已添加的 SSH 服务器之间充当桥梁。Agent 通过 Cosmosh 工作，因此它看不到你的密码或密钥，每次连接都由你批准，且每一步操作都会记入审计日志。

MCP 访问**默认关闭**。在你开启之前，不会暴露任何东西。

## Agent 能做什么

连接后，Agent 可以：

- **列出你的服务器** —— 只有名称、主机与用户名；绝不含凭据。
- **打开可见 SSH 标签页** —— 默认模式会在你批准后创建并聚焦普通 Cosmosh 终端。
- **运行隔离的后台命令连接** —— 仅当 Agent 显式请求 background 模式时使用。
- **附加现有 SSH pane** —— 由你选择 pane；Agent 永远不会收到终端列表或 Cosmosh 内部 tab、pane、session id。
- **执行命令**（在它已打开的连接上），受你的命令策略约束。
- **关闭**它自己打开的连接。

Agent 永远无法读取你存储的密码或私钥，无法新增或编辑服务器，也无法代你信任新的主机指纹。

## 开启 MCP 访问

1. 打开 `设置 > MCP`。
2. 启用 `MCP 访问`。
3. 在同一页面查看配对、客户端配置、已连接客户端、连接与待处理授权。

在 MCP 启用期间，Cosmosh 会保留一个小的本地文件，让桥接找到正在运行的应用。关闭 MCP 会将其删除。

## 接入你的 Agent

1. 在 `设置 > MCP` 中找到 `客户端配置` 区块。
2. 选择与你的客户端匹配的形式：
   - `.mcp.json` —— 用于 Claude Code（以及 Cursor）。
   - `claude_desktop_config.json` —— 用于 Claude Desktop。
   - `原始命令` —— 用于单独填写命令的客户端。
3. 复制片段并粘贴到客户端的 MCP 配置中，如客户端需要则重启它。

该片段指向 Cosmosh 为你安装的小启动器，因此无需手动复制端口或令牌。客户端配置面向安装版（打包版）生成。

## 配对令牌

Agent 使用**配对令牌**向 Cosmosh 认证。你可在 `设置 > MCP` 的 `配对令牌` 区块中管理它：

- **轮换** —— 签发新令牌并使旧令牌失效。明文仅显示**一次** —— 若某客户端需要直接使用，请及时复制。（生成的客户端配置使用启动器，无需你粘贴令牌。）
- **吊销** —— 立即使当前令牌失效，在已连接 Agent 的下次请求时切断它们。

只要你怀疑某个客户端不应再有访问权，随时可以轮换或吊销。

## 批准连接与命令

- **打开连接始终会先征询你。** 对话框会显示是哪个 Agent 在请求、哪台服务器，以及它给出的原因。在你批准前不会建立任何连接。
- 普通 open 默认创建带 Agent 标记的可见 SSH tab，并在批准后立即聚焦。标记为`后台`的请求不会出现在标签栏中，而是使用隔离命令执行。
- **附加终端同样会先征询你。** 选择器默认当前合格 SSH pane，并列出其他 SSH pane。无法共享的 pane 会显示具体原因，例如尚未就绪、缺少可信 Remote Enhancements，或已属于另一个 Agent。
- Cosmosh 会在建连前立即确认服务器名称、主机、端口与用户名仍和对话框一致。如果服务器已变化，请求会停止，Agent 必须重新发起授权。
- **命令遵循你在 `设置 > MCP` 中选择的策略**，并可在每台服务器的编辑表单上按服务器覆盖：
  - `关闭` —— Agent 不能在该服务器上执行命令。
  - `每次询问`（默认）—— 你确认每一条命令。
  - `连接内放行` —— 你确认连接内的首条命令，随后可放行该连接内的其余命令。

策略变更会在下一条命令生效。编辑服务器也会清除该连接上已有的`连接内放行`授权。

授权对话框仅在 Cosmosh 窗口打开时出现。若你离开且请求在两分钟内未被回应，它会被自动拒绝。

Cosmosh 会先记录每一条授权请求与决定，再据此执行操作。若本地审计日志不可用，请求将被拒绝，且不会执行远程操作。

## 在共享终端中工作

- Attached pane 始终是你的终端。Agent 命令运行期间，你仍可以输入、粘贴或按 `Ctrl+C`；Cosmosh 会把这次介入标记给 Agent。
- Pane 上方的紧凑状态栏会显示 Agent 名称、空闲/运行状态，以及当前可见输出正在共享。**停止**发送普通 `Ctrl+C`；**Detach**移除 Agent 访问权但不关闭终端。
- Agent cancellation 或 timeout 不会自动中断远端进程。进程继续可见运行，连接会保持 busy，直到可信 shell prompt 返回。
- 原始键盘输入不会返回给 Agent，也不会写入 MCP 审计 metadata。远端程序主动回显的文字属于普通终端输出，可能被包含在 Agent 命令结果中。
- 共享终端自动化依赖可信 Remote Enhancements。能力不可用时，Cosmosh 会拒绝操作，而不会静默切换到 background 模式。当前版本不支持附加本地终端。

## 关注活动

- `设置 > MCP` 会列出已连接客户端、带 mode/status 的活跃连接以及待处理授权请求。关闭 attached 连接只会 detach；显式关闭 Agent 创建的 terminal 连接会关闭其 tab。
- 每一次 MCP 操作都会写入审计日志。打开 `审计日志` 并按 `MCP` 类别筛选，即可复查连接、命令与授权决定。

## 关闭它

随时可在 `设置 > MCP` 中禁用 `MCP 访问`。已连接 Agent 会被断开，background 连接会关闭，可见 attachment 会移除，而 SSH tab 会作为普通用户 tab 保留。发现文件会被删除。吊销配对令牌遵循相同的可见终端保留规则。
